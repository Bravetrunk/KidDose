# KidDose reference documents

This directory contains the source material that informed the product, technical, visual, and dose-table decisions in the app.

| File | Purpose |
| --- | --- |
| `pediatricdose.pdf` | Pediatric dose table reference included with the project. |
| `Software_Requirements_Specification_(SRS).pdf` | Product scope, functional requirements, and acceptance criteria. |
| `Technical_Design_Document_(TDD).pdf` | Intended architecture and calculation/safety engine design. |
| `Design_System.pdf` | Brand, color, typography, and interaction guidance. |

These documents are retained as project references. They are not a substitute for current prescribing information, local policy, or clinical review. When a reference conflicts with a current authoritative source, the current authoritative source takes precedence and the embedded catalog should be updated deliberately.
